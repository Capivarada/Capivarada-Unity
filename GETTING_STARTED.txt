  ├─ Press Right Mouse Button again

  ├─ Attack enemy 3 more times (4 total)

All values are tunable! Edit Player prefab:

Select Player in scene → Inspector → Player Config component:

  ├─ Move Speed           5.0      (units per second)
  ├─ Dash Force          20.0      (acceleration)
  ├─ Dash Cooldown        1.0      (seconds between dashes)
  ├─ Claw Range          15.0      (max attack distance)
  ├─ Claw Cooldown        0.5      (seconds between attacks)
  ├─ Defense Duration     3.0      (how long shield lasts)
  └─ Defense Cooldown     5.0      (seconds between shields)

Change any value and see immediate effect!
(Values persist even after closing Unity)

╔════════════════════════════════════════════════════════════════════════════╗
║                          TROUBLESHOOTING                                   ║
╚════════════════════════════════════════════════════════════════════════════╝

Problem: Can't move character
Solution: Check PlayerMovement & CharacterController exist on Player

Problem: Enemy doesn't appear
Solution: Verify Enemy layer exists, check EnemyDummy.prefab in Prefabs folder

Problem: Attack doesn't hit enemy
Solution: Enemy must be within 15 units, Enemy layer must be set correctly

Problem: Compilation errors
Solution: Go to Assets → Reimport All, then restart Unity

Problem: Prefabs won't create
Solution: Check Assets/Prefabs folder exists, look at Console for errors

👉 For more help, see: Assets/SETUP_GUIDE.md
